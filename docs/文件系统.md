#### 系统的部分逻辑
- 关于分区
    - 似乎是只能操作一个分区
    - 每个分区具有自己的根目录 `root_dir`, 位于分区第一个数据块

- 文件表 位于`file.c`
    1. 全局文件表: 操作系统最多同时打开 64 文件
    2. 进程文件表: 每个进程自己的文件表, 最多同时打开8个


- 关于目录
    1. 明确linux一切皆文件
    2. 目录也对应一个inode
    3. 目录的内容中全是目录项
    4. 目录项具有inode与type成员, 标明其对应inode与文件类型
    5. 若目录项type为directory, 则其inode对应的是一个目录

- 文件系统的操作
    1. 需要同步三个位图


- 关于超级块
    - 结构如下
    ```c
    typedef struct super_block_t {
        uint32_t magic;             //魔数
        uint32_t sec_cnt;           //扇区总数
        uint32_t inode_cnt;         //总共支持多少个inode
        uint32_t part_lba_base;     //分区起始lba
        uint32_t block_bitmap_lba;  //块位图起始扇区
        uint32_t block_bitmap_sects;//块位图扇区数
        uint32_t inode_bitmap_lba;  //inode位图起始扇区
        uint32_t inode_bitmap_sects;//inode位图扇区数
        uint32_t inode_table_lba;   //inoda数组起始扇区
        uint32_t inode_table_sects; //inode数组扇区数
        uint32_t data_start_lba;    //数据块起始扇区
        uint32_t root_inode_no;     //该分区根目录inode下标(通常为0)
        uint32_t dir_entry_size;    //目录项的结构体大小
        /* 主要是要满足硬盘一次读取512字节 */
        uint8_t pad[460];           //空, 填满512字节
    } __attribute__((packed)) super_block_t;
    ```
